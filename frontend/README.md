# Aab-e-Noor Water Sales (Demo)

Development instructions

Install dependencies:

```bash
npm install
```

Run dev server:

```bash
npm run dev
```

Build:

```bash
npm run build
npm run preview
```

If `npm install` fails on Windows PowerShell with an execution policy/security error, run in an elevated terminal or use a standard Command Prompt (cmd.exe) or Git Bash. You can also run:

```powershell
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
```

and then retry `npm install`.
